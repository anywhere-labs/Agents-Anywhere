# Codex 原生计划审阅

从 #183 拆出，仅对 app-server SDK 路径的原生 `plan` 条目在成功结束回合后创建审批。普通文字计划、`turn/plan/updated` 进度、失败/中断回合不会触发计划执行入口。重复完成事件不重复创建审批。

批准后以 default collaboration mode 发起下一轮；修改意见以 plan mode 继续规划。恢复失败时保留计划供重试，已有运行回合或结束的审批不能再次执行。模型为空时先从原生线程读取模型与推理设置。

本改动不包含计划卡片 UI 或 Markdown 编辑，不新增进入计划模式的开关。本项基于 #183 拆出的共享审批卡片评审；批准与修改意见使用该卡片，不向通用工具审批假定新的输入语义。原生 Codex App 的 IPC 接管路径保持现状，本项不声称已经覆盖 IPC 原生计划审阅。

# 计划 Markdown 编辑与自动保存

从 #183 拆出，基于共享计划审批卡片（#183 的第一部分），不包含 Codex Runtime 计划识别。聊天区保留紧凑计划卡片，右侧工具栏提供 Markdown 文档编辑；批准时发送当时草稿，批准之后继续编辑文件不会自动给 Agent 发消息。

Web 与 Desktop 同步实现。计划文件保存在会话工作目录中，文件名根据 notice ID 摘要生成；重新打开读取已保存正文。写入使用 ifMatch，文件被其他程序修改时保留当前草稿并显示失败，不覆盖磁盘内容。自动保存串行化，保存过程中继续输入不会丢失最后一次更改。

Connector 的文件写入将空 ifMatch 视为“文件必须不存在”，用于防止首次创建文档时覆盖竞争创建的文件。读取失败时不能写入旧 notice 正文。错误状态保留编辑并提供重试入口。

不新增 Server API 或 Runtime 事件；Android/iOS 不提供专用编辑界面。自动化检查不等于真实远程文件系统或真机联调。

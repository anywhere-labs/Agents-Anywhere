# V3 数据保留、自助删除与 2.x 切换（T48）

状态：随[架构方案](architecture-proposal.md)提交评审，所有新增期限和范围待负责人批准。本文不包含可执行清库命令，也不授权操作生产。

## 1. 范围和不能撤回的事实

已确认方向：V3 上线清空旧对话及 Timeline，保留账号、必要设备和运营数据。M20 的「AA 2.x 之前」按本稿提议解释为 V3 切换前的全部 2.x 及更早云端对话，不自动删除用户工作目录或 Runtime 原生记录；此解释随方案一起确认。旧数据不自动重新导入 V3，也不从本机 Runtime 历史自动批量发布。用户明确导入时仅进入本机，不回传控制面。

#266 中已经上传的凭据可能被复制，任何清理均不能收回已经外泄的秘密。上线告知必须提示曾在会话中出现的凭据应轮换；不承诺用扫描识别所有受影响用户或秘密。保留账号不等于保留账号下所有配置 JSON，保留运营数据不等于保留关联 session/path 的原始记录。

M75/M76 明确设备双模式：E2EE 阻止服务器读取传输内容；普通模式只提供 TLS 与账号授权，Router 可见转发业务，但仍禁止云端正文持久化与日志采集。两模式均须处理旧数据，不能将普通模式宣传为同等 #266 机密性保护。

## 2. V3 云侧字段白名单与建议期限

表内逐项列出允许字段，未列出的字段默认拒绝采集。正式 schema/日志均做白名单校验；未知字段不能透传。期限为推荐待批：以用途结束或表列最大期限中先到者为准，注销另有更短要求的执行更短值。

| 类别 | 允许字段 | 用途 / 最长期限 / 删除方式 |
| --- | --- | --- |
| 账号 | 随机 user id、登录 provider/subject、必要 email、password hash、角色/禁用状态、创建/更新时间、协议同意版本/时间 | 登录与账号服务；存续期，注销主存储目标 24 小时删除。展示名/头像仅用户选填，不能承载会话派生字段 |
| 设备发现 | 随机 device id、owner id、OS 类别、客户端/协议版本、在线状态、最后在线/注册时间、注册 token 摘要、撤销状态、设备报告的模式提示（非客户端安全权威） | 路由/兼容；设备存续期，解绑 24 小时删；默认不上传主机名/IP 清单/绝对路径，用户选填别名可随时删除 |
| 路由认证 | 随机 tunnel/request id、目标 device id、最小 service/method scope、票据摘要、签发/到期/撤销时间、传输协议版本 | 建连与防重放；票据 5 分钟；活动记录结束后 24 小时清除，不保留握手秘密/证明正文 |
| 账号登录令牌 | 不透明 token 摘要、owner/client id、scope、到期/撤销时间；OAuth provider 必需秘密单列受保护 | 账号身份目的，与模型 OAuth/模型密钥分离；不把模型凭据留云；注销立即吊销，主存储 24 小时清除 |
| 运营明细 | 随机事件 id、小时桶、产品/OS/协议版本类别、枚举事件/结果码、字节/时长/次数 | 故障/成本分析；7 天，禁止 session/runtime 自定义名、用户/设备稳定关联标识、dedupe 内容、路径、自由文本 |
| 匿名聚合 | 日期/小时、粗粒度 OS/版本类别、计数/流量/时长桶 | 趋势 13 个月；不含 user/device/session id，低样本维度合并，禁止从原文构建标签 |
| 安全/删除审计 | 随机操作 id、动作枚举、状态、开始/完成/过期时间、数量、结果枚举 | 核对注销与清理；最多 30 天。活动期 owner 关联在删除完成后移除；不存邮箱、路径、被删正文或 token |
| 诊断日志 | 时间、部署构建、随机请求 id、结果枚举、耗时/长度桶 | 7 天；IP 不落持久日志，速率限制临时数据最多 24 小时。反向代理/CDN/APM 同样适用，禁 query/headers/body |
| 待删除投递 | 随机删除操作 id、device id、授权/数据 id 的最小引用、待处理状态/到期时间 | 告知离线设备；最多 30 天。设备账号租约到期即停远程，不能靠保留待办无限收集设备信息 |
| 云备份（账号等允许数据） | 上述白名单字段的一致性备份，独立备份 id/日期 | 最多 30 天，隔离访问；恢复前重放删除清单，不把已注销账号/已删除内容复活 |

控制面不保留端点私钥、配对秘密/密文包、会话密钥或本地授权原件；E2EE 长期身份公钥由可信带外/端内加密交换，不上传云端。模式提示只能用于发现，不能改变客户端本地要求或设备策略。运营字段若因计费/法定留存另有需求，先让负责人批准并独立告知，不借「运营数据」放行全部旧表。

本机原始会话/附件默认留到用户主动删除，不擅自按天清空；日志目标 7 天；可重建客户端缓存目标最多 7 天未访问即淘汰，撤销/退出立即尽力清除。敏感缓存用 OS 保护的密钥加密，Web 密钥/页面来源限制见主方案；用户自行导出的备份由用户管理，不对其承诺远程销毁或固定期限。

## 3. 旧数据盘点：必须按字段投影，不能直接保表

核对入口：[当前 schema](../../server/agent_server/infra/db/schema.py)、[Goal schema](../../server/agent_server/infra/db/goal_schema.py)、[Redis 协调](../../server/agent_server/infra/redis_coordinator.py)及迁移目录。下表是已识别对象，实施前还需生成实际部署资源/列清单并由运维复核；不能把源码中没看到的桶、日志或备份视为空。

| 已识别对象 | 切换要求 |
| --- | --- |
| `sessions`、`timeline_items`、inventory/active runs/receipts、shares | 删除对话、标题、摘要、外部会话关联和分享凭据；撤销公开链接，不能只删正文留摘要 |
| `projects`、terminal roots、preview tokens | 云端项目名/工作目录、终端 cwd/root、预览 path 与 token 全清，不作为必要设备信息保留 |
| workflows、planning、plan documents/operations/creations、Goal 状态/操作/outbox | 清请求、结果、payload、缓存和待投递；这些可能含提示/计划/路径，不属于可豁免运营数据 |
| `legacy_import_archive`、迁移遗留/导出副本 | 清对话及含敏感配置的归档 payload，禁止借历史归档保留原文 |
| `connectors` 及 runtime/catalog/capability 表 | 只投影第 2 节必要设备字段；清 preferences/settings/config/error/phase/catalog/defaults/metadata/discovery 等任意 JSON 及自定义名，不原样迁表 |
| `tokens_links`/states、model profiles/assignments/selections、旧配对 code、登录/预览临时 token | 模型/OAuth 凭据和配置不迁云白名单；撤销、清除并指导本机重新授权。账号 OAuth 身份关联与模型 OAuth 分开核对，勿误删登录必需 provider subject |
| `usage_events` 与按 session/runtime/user/device 统计表 | 移除会话关联和可识别维度，按第 2 节重新聚合；`SET NULL user_id` 不会自动清 session/connector/dedupe 等字段 |
| Redis Timeline 写缓冲、实时广播/重放/通知队列、后台 job | 先停生产者、停止/清空消费者，再按业务 namespace 删除。盘点 AOF/RDB 和副本；禁止对共享 Redis 不分范围 flush |
| 对象/本地 transfers、附件、缩略图、预览、搜索/向量索引、CDN | 清所有版本/未完成分块/临时对象/缓存及派生索引；仅删数据库引用不算清理完成 |
| 网关/Server/Connector 日志、APM/Sentry、崩溃/core、诊断包 | 盘点正文/凭据可能进入的位置；云端历史明文副本清除或隔离至到期；本机原始日志由用户控制并提供清理入口 |
| PostgreSQL 备份/WAL/PITR、Redis AOF/RDB、对象版本及离线备份 | 记录副本/负责人/不可变保留期限；先隔离禁用普通恢复，最多 30 天到期销毁，未能满足须阻止对外承诺清理完成并升级决策 |
| Web/桌面/Android/iOS 旧缓存、通知、用户导出 | 客户端升级时清旧云会话缓存；push 清已知通知并停旧正文推送；离线端待处理，不能保证收回用户导出或第三方已接收内容 |

## 4. 自助删除与账号注销状态机

对用户分别提供「删除本机会话」「清除此端缓存」「解绑远程设备」「注销账号」，说明会影响哪些设备、原生 Runtime 历史/工作文件是否也删。默认会话删除包含 AA 管理的消息、附件、索引和队列，不删除工作目录、代码仓库、未由 AA 管理的模型 CLI 历史；需要删原生记录时单独确认并按 Runtime 能力执行。

删除操作有持久化幂等 id，状态为 requested → access_revoked → local_pending / deleting → primary_deleted → backups_pending → complete。`complete` 要以各已知受管副本和可控备份的实际证据为准；长期离线/失窃端标记 unverifiable，界面明确未能擦除，不能假冒全设备完成。用户自管副本列为能力边界，不能永远阻塞账号主存储删除。

1. 验证操作者持有相应权限；注销要求近期账号认证，不能仅凭泄露链接触发。控制面认证只能注销账号，E2EE 不能越过配对执行本机业务；普通模式按既定账号/操作权限，均不得将账号注销自动扩大为删除用户工作文件。
2. 立即撤销票据/注册凭据、取消通知和远程访问；本机停该会话新写入和待发队列，尝试中断 Runtime，持久化删除标记后向已授权客户端发清缓存事件。无法取消已执行命令时报告事实。
3. 删除本机业务数据和可控缓存/附件，保留不含正文的最小删除标记直到旧备份失效，防重连或恢复把内容补回来。分页、搜索、watch 一起失效；迟到事件不得复活会话。
4. 离线本机/客户端下次上线先处理删除/撤销，再取业务快照；最多 24 小时账号租约限制诚实失联实例远程访问。待办 30 天到期后删最小路由记录，旧账号 token 仍永久无效；用户本机离线内容需手动清理，云不能保证远程擦除。
5. 注销主账号、设备关联和可识别运营信息目标 24 小时内删除；不可逆匿名聚合可按期限保留。备份待删时显示最迟到期日，不用「已注销」暗示所有磁盘字节已立即消失。
6. 恢复只能在隔离环境进行，先应用删除清单及凭据撤销，再开放流量；过期备份、缺删除清单或跨清理边界的恢复一律阻止。不能恢复旧注册 token 或本机配对来绕过新配对。

## 5. V3 切换与回滚步骤（尚未授权执行）

1. **批准与告知**：负责人批准范围、期限、兼容端版本和停服窗口；告知旧云历史不迁移、分享失效、模型需本机重新授权、凭据轮换建议。需要导出时提供用户主动本地保存且提示敏感性的方式，不额外生成运营方明文备份。
2. **盘点与演练**：按真实部署列出所有数据库/namespace/桶/版本/副本/备份/日志出口；用一次性环境和无效合成秘密演练，核对保留白名单投影和离线端。演练材料不含生产秘密。
3. **写入栅栏**：停止旧 Connector 发布/HTTP transfers/通知/导入/后台刷新/队列；下线旧票据和写接口，隔离业务 namespace。老客户端继续运行不能重新上传，不能靠「提醒升级」防复活。
4. **最小迁移**：只把允许的账号/设备/匿名统计投影到新控制面，旧设备注册凭据不直接继承远程执行权；E2EE 设备的每个客户端重新取得独立配对，普通模式重新按账号权限签发，不能把旧凭据当作 E2EE 客户端证明。
5. **清理主副本**：执行经过 review 的版本化迁移/清理程序（之后另交 PR），按第 3 节清数据库、缓存、对象所有版本、索引与派生数据。生成计数、资源清单、时间、结果码审计；不把旧正文写进清理日志。
6. **隔离备份**：旧备份转隔离、限制恢复人员，登记最晚销毁日；只有有证据证明原本即独立加密且密钥全部销毁时才能说密码学擦除，事后加密不能抹掉历史明文副本。不可变备份超出 30 天须负责人重新决定，不能虚报满足期限。
7. **验收后放行**：用合成秘密检查云持久化和旁路，验证四端缓存、离线待办、旧客户端写入拒绝和恢复拦截；负责人另行批准开启 V3。到期验证全部可控备份销毁，更新删除状态。
8. **回滚**：只回滚程序/功能开关到经验证且遵守同一删除边界的版本；不得重开旧上传、恢复旧对话/密钥备份或把本机明文补回 Server。不能安全恢复时保持维护模式/仅本机功能，并请求负责人决定，不自动回滚到有敏感历史的 2.x 服务。

上线窗口、真实留存资源、运营/法律额外要求、原生 Runtime/四端差异仍是实施和上线前的核验条件。本稿的批准不会触发清库或替代上线批准。

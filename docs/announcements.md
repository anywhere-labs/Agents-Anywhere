# 公告

管理员在管理页面的「公告」卡片编辑 Markdown、预览内容并保存。开关关闭时保留草稿，公开接口不返回草稿内容。公告默认关闭，最多支持 20,000 个字符；空白内容不能启用。

登录、注册和主界面进入时检查公告。页面重新获得焦点或恢复可见时也会检查，两次焦点检查至少间隔一分钟；没有持续轮询。请求失败不影响原页面功能。

## 发布时间与已读记录

- 首次启用、修改已启用的内容，以及关闭后重新启用，都会生成新的 `publishedAt`。
- 未修改内容直接保存不改变发布时间。关闭或编辑关闭状态下的草稿也不改变发布时间。
- 时间由服务端产生，按毫秒严格递增；多 worker 使用共享协调锁保护一次完整保存。
- 关闭弹窗或点击「我知道了」，记录当前公告的服务端发布时间，不使用浏览器当前时间。
- 已读记录保存在当前站点的浏览器 localStorage，键名为 `aa.announcement.read.v1`，登录前后共用，多个标签页同步。不同浏览器和设备分别记录。
- 浏览器禁止持久化存储时，当前标签页仍能记住已读状态；重新打开标签页可能再次提示。

Markdown 使用现有渲染组件，支持标题、列表、链接、代码和表格，不执行原始 HTML。

## 接口

| 方法与路径 | 权限 | 内容 |
| --- | --- | --- |
| `GET /api/v2/announcement` | 无需登录 | 返回已启用公告，关闭时 `announcement` 为 `null` |
| `GET /api/v2/admin/announcement` | 管理员 | 读取开关、草稿和上次发布时间 |
| `PUT /api/v2/admin/announcement` | 管理员 | 完整保存 `{ "enabled": true, "markdown": "..." }` |

公告作为单条 JSON 存放在已有 `instance_settings` 表的 `public_announcement` 设置中，无须迁移数据库。公开读取不缓存，避免停用或更新后继续返回旧内容。重建整个业务库会同时清除公告设置。

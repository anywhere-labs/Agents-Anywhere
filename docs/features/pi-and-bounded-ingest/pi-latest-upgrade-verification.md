# 三平台 Pi 1.1.0 升级与验证

## 授权与范围

用户确认只升级 Windows、macOS、Linux 上的 Pi 和必要运行时，再验证运行情况。
不升级 Agents Anywhere、Connector 或其他项目依赖，不更新 Pi 用户扩展，不发送
真实模型请求，不推送仓库。本轮核对 GitHub 稳定 release 与 npm latest，均为 1.1.0。

## 最终版本

| 平台 | Pi | Pi 使用的 Node | 处理 |
|---|---|---|---|
| Windows | 1.1.0 | 24.14.0 | 已是最新，未重装 |
| macOS arm64 | 1.1.0 | 22.19.0 | 从 0.87.1 升级，保留原 Node |
| Linux x86_64 | 1.1.0 | 24.21.0 | 从 0.87.1 升级，保留原专用 Node |

Linux 登录终端里的 Node 20.19.2 不是原 Pi 启动器显式使用的 Node。本次复核旧
启动器确认，Pi 原来使用的专用 Node 已是 24.21.0，满足新版要求，最终保持不变。
准备过的 Node 22.23.3 验证副本已确认由本轮新建、没有使用进程、内容符合官方
摘要后移除；校验过的归档保留在备份中。没有替换系统 Node 或其他服务的运行时。

## 升级方式与数据保护

- 升级前检查目标用户的 Pi 进程，没有检测到运行中的 Pi 会话。
- 按已有安装方式精确安装 `@earendil-works/pi-coding-agent@1.1.0`，禁用 npm
  lifecycle scripts、audit 和 fund；不调用旧版含义不同的 `pi update`。
- Mac 使用原 npm 全局前缀；Linux 只更新原来仅声明 Pi 的专用 npm 前缀。
- Linux 启动器保留原数据目录、遥测设置和 Node 路径，只适配新 CLI 入口。
- 旧软件、启动器、前缀清单及必要配置均备份在目标用户的私有目录：
  `$HOME/.local/state/pi-upgrades/<本轮备份编号>/`。软件归档做过恢复检查。
- 升级后配置文件哈希保持一致，历史文件路径/大小/mtime 清单摘要保持一致。
  没有复制或提交真实配置、模型凭据、历史内容、账号或服务器地址到仓库。

Mac 第一轮因隔离 npm 配置指向同一空文件而失败，已自动回滚并保留记录；改为
两个独立空配置文件后升级成功。没有通过关闭安全检查或删除用户数据绕过失败。

## 验证结果

- 三端默认 Pi 入口均报告 **1.1.0**。
- Windows 当前仓库原生 probe：真实 RPC `get_state` 成功，子进程已回收。
- Mac / Linux：加载仓库中未改动的 `PiRpcProcess` 实现，直接运行升级后的
  Node + CLI，在空 HOME、agent、cwd 中各做两轮真实启动/关闭。
- 两端每轮 `get_state` 成功、`get_messages` 为空、无 extension_error 事件，
  子进程以 0 退出。探针显式提供审批扩展资源；没有发送模型 prompt。
- Linux 以既有非 root Pi 运行用户验证，不把 Connector 改成 root。
- 验证结束后再次确认配置/历史清单未变化，备份完整。临时升级工作目录已
  清理，执行记录和可回滚的软件归档保留在私有备份目录中。

## 对旧验证记录的澄清

后续检查发现 Linux 的自定义启动器会覆盖 `PI_CODING_AGENT_DIR`。此前旧版 Linux
测试虽然证明了真实 RPC 能通信，但“进程设置空 agent 环境”并不足以证明该环境
没有被启动器覆盖。因此不把旧记录作为严格空目录隔离证据，也不据此断言真实 Pi
使用了 PATH 中的 Node 20。

本轮绕过这些目录覆盖，直接使用同一已升级安装中的 Node + CLI，清除继承的模型
凭据环境，明确设置空 agent 目录，并确认消息列表为空，从而补齐严格隔离的证据。
现用启动器的数据目录设定没有因此改变。

## 验证边界与回滚

“正常运行”在本轮指版本、启动、基础 RPC、资源加载和进程回收检查。用户自定义
扩展、AA UI → Server → Connector → 模型的完整会话、真实审批/附件与长期重连
稳定性未在本轮验收。没有真实模型调用费用。

需要回滚时，应先确认没有运行中的 Pi，再恢复备份的软件与启动器；不要把用户
后来变更的配置或新增历史直接覆盖回旧备份。现用 AA/Connector 未升级或重启。
本轮不改变 issue #278 完整快照仍未解决，以及独立 Pi 重连测试波动待查的结论。

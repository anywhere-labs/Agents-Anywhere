# Agents Anywhere 2.0.0

2.0.0 提供 macOS Universal、Windows x64 和 Android 安装包，通过 [README 下载表](../../README.md#下载与入口)中的 ModelScope resolve 链接分发。iOS 源码包含在仓库中，本记录不声明 App Store 发布。

## 产品变化

- Desktop Workbench 将客户端与受管理的本机 Connector 集成到 Electron 应用中。
- Web、Desktop 和移动端使用 v2 服务端契约，统一管理会话、Runtime、工作区及远程终端。
- 当前默认 Runtime providers 为 Codex、Claude 和 DSH；功能由有效能力决定。
- Server 使用 PostgreSQL 和 Redis，API namespace 为 `/api/v2`。
- Desktop 登录健康检查禁用 HTTP 缓存，避免缓存的 HTML 被误判为后端不正常。

## 主线切换

旧主线为 `6c47e419`，发布基线为 `0116af9d`。两者已长期分叉，v2 重写了 Runtime、API、客户端与存储架构，因此本次以发布 v2 的文件树为基线，将旧主线历史作为合并父提交保留；不直接恢复旧版接口和 ACP adapters。

旧主线独有提交按以下边界处理：

| 类别 | v2 处理 |
| --- | --- |
| 静态资源路径穿越修复（`1755bf4f` / `4c8a74ae`） | 主线切换时适配补回，并覆盖编码路径、符号链接与各 HTML fallback 的 GET/HEAD 回归。 |
| Android token 过期处理（`77bf98ac`） | v2 已有 HTTP/WebSocket unauthorized 通知及应用层处理；保留 v2 实现。 |
| Codex catalog、模型 effort 与旧 Runtime schema | v2 通过当前 SDK/provider 与有效能力契约处理，不合回旧静态 catalog 管理路径。 |
| ACP provider 及对应 Android/Web UI | 不在 v2 默认 providers 中，作为旧版能力明确记录；不宣称兼容。 |
| Windows PTY 噪声过滤、localhost QR、旧测试与镜像调整 | 未逐项移植；保留已发布 v2 的终端、登录、测试与构建行为，不能据本次合并声称这些旧补丁已全部覆盖。 |

## 分发与后续版本

当前安装包中的 Desktop / Android 更新 URL 仍是 `.invalid` 占位地址。ModelScope 手动下载已可用，应用内自动下载尚未接入。后续发布需要先配置真实的按平台分发地址，再构建新安装包；只上传文件不会更新旧客户端配置。

后续版本应记录各平台来源提交和文件摘要，使用新的版本文件名，更新下载入口并完成对应平台验证。签名、公证凭据只从安全环境注入。GitHub 的历史 0.1.x Releases 与 ModelScope 2.0.0 分发是两个不同记录。

部署升级与回滚请使用[升级指南](../upgrading.md)，开发和打包见[开发指南](../development.md)。

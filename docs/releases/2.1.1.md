# Agents Anywhere Web / Desktop 2.1.1

本次仅更新 Web 与 Desktop，沿用 2.1.x 接口；Server、Connector、Android、iOS 和 DSH 插件无需升级。

- 修复快速回复已完成，但 Web / Desktop 仍显示「正在工作」的问题（#303）：首次订阅或断线重连后的事件补拉成功时，再读取运行状态。
- 运行状态与能力信息并行读取，分别处理失败；Connector 离线时也读取 Server 最后持有的运行状态。
- 请求前已收到的运行状态参与版本判断，请求期间收到的实时事件在读取结果之后应用；更旧的状态不会覆盖新状态。读取失败保留已有状态，切换会话或连接代次变化后不应用过时读取结果。

本次不改变 Server 快照、状态缓存及事件补拉实现，未处理这些路径内部的并发一致性窗口。安装包构建与发布记录待发布时补充。

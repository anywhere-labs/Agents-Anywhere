# Agents Anywhere 2.1.1

2.1.1 是一次各端同步的小版本更新（PATCH）：修复会话列表换位抖动、新增「进行中的任务」视图、Android 跟手动效与抽屉，以及停止维护苹果系客户端。不含接口变化。

## 问题修复

- Web / Desktop / Android：左侧会话列表不再频繁换位。此前只有 `running` 一个状态会被固定在顶部组，`waiting_approval`、`blocked` 等状态在每次翻转时会把会话在两个排序组之间搬来搬去；非活跃组的排序键 `sortAt` 又会随后台同步推进。现在六个"工作中"状态共享一个固定组（组内按 id 恒定排序），非活跃会话改用最后一条用户可见 timeline 条目的时间排序，仅后台同步不再改变顺序。
- DSH 插件：稳定名 tarball（`agents-anywhere-dsh-bridge-next.tgz`）在已有 lockfile 的 profile 中升级会触发 `ERR_PNPM_MISSING_TARBALL_INTEGRITY`。发版流程明确以版本化 URL 为唯一安装地址，并新增 `manifest.json` 清单（含 sha512 integrity）与用户侧修复命令；详见 [插件分发规范](../plugin-distribution.md)。

## 产品变化

- Web / Desktop：会话筛选菜单新增「状态 → 进行中」。该视图列出所有设备上 Agent 正在工作（含等待批准、阻塞）的会话，每行附带 `设备 · Agent` 身份与实时状态标签（运行中/等待中/排队中/停止中/等待批准/阻塞），项目分组与置顶列表同步响应。
- Android：主页会话列表顶部新增「进行中的任务」板块，跨设备汇总工作中会话（设备 · 状态）；项目视图的筛选菜单同步新增「进行中的任务」。列表行与项目树项启用 `animateItem` 弹簧动画，换位时平滑滑动；个人资料抽屉改为跟手拖拽（左缘起手或开态全表面），拖动过程 1:1 跟随手指、松手后弹簧结算，仿 RikkaHub 手感。
- Desktop（交付）：发布 CI 现产出 Linux AppImage 与 Windows NSIS 安装包；macOS 不再产出。端内更新按构建期烙入的平台地址下载。
- 平台策略：iOS 与 macOS 客户端自本版本起停止维护，仓库不再为苹果系客户端新增功能或修复，发布 CI 不再产出 darwin 产物。

## 升级提示

- Web / Desktop / Android：服务端升级到 2.1.1 后，各端按既有链路提示更新；Android 与 Desktop 新包下载地址已在 2.1.0 周期打通。
- Windows：存量旧包（未烙入下载地址）第一次仍需从下载页手动安装，其后端内更新可用。

完整的更新说明见 GitHub Release。

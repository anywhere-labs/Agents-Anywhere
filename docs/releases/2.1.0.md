# Agents Anywhere 2.1.0

2.1.0 是一次接口更新（MINOR）：DSH Bridge 契约新增会话洞察（session insights）字段，Server 的 `runtime.state.updated` 现在会把 `metadata.insights` 的变化实时推送给客户端；`session.turnEnded` 新增可选的精确单轮 token 账目 `usage`。旧客户端遇到新字段会忽略而不是出错，旧 Server 下新客户端自动隐藏相关组件。

## 接口变化

- `contracts/dsh-bridge/1.0`：`session.state.updated` 的 `metadata.insights` 携带 `tokenUsage`、`contextPressure`、`sessionStats`、`goal`、`todos`、`subagentCatalog`（全部可选，键缺失表示 DSH 未挂载对应能力）；`session.turnEnded` 新增可选 `usage`（精确单轮 token 结算）。
- Server：runtime state 的变更检测纳入 `metadata.insights`，因此仅统计数据变化也会发布 `runtime.state.updated`；其余事件与端点不变。
- 最低配套：统计与目标面板需要 Server ≥ 2.1.0；任一旧端与新端混跑时功能自动降级隐藏。

## 产品变化

- Web / Desktop：对话输入框底部显示当前会话总数据（轮次/步数、解码速度 tok/s、累计 token 与缓存命中率、上下文占用百分比）；每轮回复的操作行显示该轮「用量 xx tok」；标题栏新增洞察徽章，展开可见 Agent 预设、对话目标（阶段/轮次/阻塞原因）、任务面板与子 Agent 列表，点击子 Agent 可切换查看其会话进度。
- Android：与 Web 相同的统计条、单轮用量与洞察弹窗；新增 WorkManager 周期兜底通道，进程被系统或电池策略回收后仍会定期补发会话等待/完成/失败通知。
- DSH 插件：新增会话洞察采集与推送，冷会话通过日志回放读取，不影响首屏性能。
- iOS：本次仅版本号同步，未跟进新组件（计划后续版本补齐）。

完整的更新说明见 GitHub Release。

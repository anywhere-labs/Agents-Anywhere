# Agents Anywhere 2.1.0（未发布）

本次更新扩展 DSH Bridge 本机协议，修复大历史在持续上传超过固定 ACK 等待窗口时反复重新同步的问题。按[版本号规则](../versioning.md)，所有端的产品版本标识统一为 2.1.0；本文件不代表安装包已经发布或通过真实设备验收。

## 接口变化与最低配套版本

- DSH Connector 在 `runtime.sync.subscribe` 中请求 `uploadProgressVersion:1`，Bridge 支持时在响应中返回该版本。
- 新增 `runtime.sync.progress {streamId,batchSeq,bytesSent}`。累计上传字节增加时，Bridge 重置当前批次的 60 秒无进展计时器。进度不提交批次、不释放下一批次，也不保存检查点。
- 使用此修复需要 Connector 和 DSH Bridge 均为 **≥ 2.1.0**。任一端为旧版本时不启用进度扩展，保留原同步行为，也保留其慢速上传限制。
- Server、Web、Desktop、Android、iOS 没有新增依赖字段。此次本机扩展不要求这些端升级才能同步；版本号变更用于保持产品 MINOR 一致。

Server API、数据库 schema 和完整历史替换语义没有变化，不需要数据库迁移。HTTP 仍一次提交完整快照；真正失败的上传仍可能完整重传，不提供云端断点续传。实现及验证方式见[慢速上传说明](../dsh-slow-upload.md)。

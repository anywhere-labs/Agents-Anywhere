# Agents Anywhere 2.1.0

2.1.0 是一次接口更新（MINOR）：DSH Bridge 契约新增会话洞察（session insights）字段，Server 的 `runtime.state.updated` 现在会把 `metadata.insights` 的变化实时推送给客户端；`session.turnEnded` 新增可选的精确单轮 token 账目 `usage`；`/health` 新增移动端更新指针字段。旧客户端遇到新字段会忽略而不是出错，旧 Server 下新客户端自动隐藏相关组件。

## 接口变化

- `contracts/dsh-bridge/1.0`：`session.state.updated` 的 `metadata.insights` 携带 `tokenUsage`、`contextPressure`、`sessionStats`、`goal`、`todos`、`subagentCatalog`（全部可选，键缺失表示 DSH 未挂载对应能力）；`session.turnEnded` 新增可选 `usage`（精确单轮 token 结算）。
- Server：runtime state 的变更检测纳入 `metadata.insights`，因此仅统计数据变化也会发布 `runtime.state.updated`；其余事件与端点不变。
- Server `/health` 新增可选字段：`androidUpdateUrl`（配置 `AGENT_SERVER_ANDROID_UPDATE_URL` 时返回，Android 客户端优先用该地址下载 APK）与 `iosStoreUrl`（默认官方 App Store 页面，可用 `AGENT_SERVER_IOS_STORE_URL` 覆盖，iOS 客户端用它做应用内更新跳转）。旧客户端忽略新字段。
- Desktop 安装包下载地址改为构建期按平台烙入（`WORKBENCH_UPDATE_URL_LINUX/WIN32/DARWIN` → `build-info.json`），运行时按 `process.platform` 选择；Server 下发的地址仍视为不可信，不参与下载决策。
- 最低配套：统计与目标面板需要 Server ≥ 2.1.0；任一旧端与新端混跑时功能自动降级隐藏。

## 产品变化

- Web / Desktop：对话输入框底部显示当前会话总数据（轮次/步数、解码速度 tok/s、累计 token 与缓存命中率、上下文占用百分比）；每轮回复的操作行显示该轮「用量 xx tok」；标题栏新增洞察徽章，展开可见 Agent 预设、对话目标（阶段/轮次/阻塞原因）、任务面板与子 Agent 列表，点击子 Agent 可切换查看其会话进度。
- Android：与 Web 相同的统计条、单轮用量与洞察弹窗；Agent 预设显示中文名称，新建会话支持选择预设（创建请求经 `runtimeOptions.agentPreset` 送达 DSH）；新增 WorkManager 周期兜底通道，进程被系统或电池策略回收后仍会定期补发会话等待/完成/失败通知；应用内更新端到端可用（优先 Server 下发地址）。
- Desktop：CI（`.github/workflows/desktop-release.yml`）在原生 runner 构建 Linux AppImage、Windows NSIS、macOS 通用 DMG 与 DSH 插件 tarball；无签名配置时产出未签名产物（macOS 首次打开需右键「打开」，Windows 需在 SmartScreen 选「仍要运行」）。端内更新弹窗→下载→打开安装器的链路不变，下载地址按平台烙入。
- iOS：Server 版本高于本机应用时，登录后弹窗提示并可一键跳转 App Store / TestFlight 更新（「稍后再说」按版本记忆，不重复打扰）。该部分代码未能进行 Xcode/真机验证。
- DSH 插件：新增会话洞察采集与推送，冷会话通过日志回放读取，不影响首屏性能；产物以 npm tarball 分发，`dsh --profile <名> plugin add <tarball 地址>` 一条命令升级。
- Web：无新功能，版本号同步。

完整的更新说明见 GitHub Release。

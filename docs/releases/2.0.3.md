# Agents Anywhere 2.0.3

2.0.3 提供 macOS Universal、Windows x64 和 Android 安装包，发布在 GitHub 的 [v2.0.3 Release](https://github.com/anywhere-labs/Agents-Anywhere/releases/tag/v2.0.3)，同样的文件也通过 [README 下载表](../../README.md#下载与入口)中的 ModelScope 链接分发。iOS / iPadOS 在 [App Store](https://apps.apple.com/cn/app/agents-anywhere/id6787125178) 下载，也可以通过 [TestFlight](https://testflight.apple.com/join/GKGaut99) 安装测试版；各端的 PATCH 版本独立发布（见[版本号规则](../versioning.md)），iOS 不在本次安装包记录中。

## 产品变化

- 指令菜单：在 Web、Desktop 和 Android 的输入框中输入 `/`，可以查看并执行当前 Agent 支持的指令；Codex 会话支持原生 `/compact`。
- Desktop 内置 Python 3.12，本机 Connector 不再下载或借用系统 Python；首次启动仍需联网安装依赖。
- 管理员可以发布服务公告；新增邮箱找回密码（默认关闭）和团队成员分页，创建用户时可以跳过邮箱验证。
- Web / Desktop 的会话列表显示 Agent 图标和设备、项目信息，项目可以按设备和 Agent 筛选；对话内容支持 LaTeX 和 Mermaid。
- Android 新增指令菜单、服务公告和项目筛选；交互请求面板可以收起，并支持直接回复文字。
- Connector 重启或重新连接后，Codex 会话增量恢复；Claude Code 在后台任务和定时任务运行期间保持会话活跃，模型列表改为读取本机 Claude Code。
- Windows 修复 Runtime 存储写入报错（EBADF）以及 Codex 脚本的查找与启动。

完整的更新说明见 [GitHub Release](https://github.com/anywhere-labs/Agents-Anywhere/releases/tag/v2.0.3)。

## 来源提交

标签 `v2.0.3` 指向 `c0c3810d`。各端版本号在 `2095862f` 统一为 2.0.3。

- Desktop：`desktop-workbench/`、`connector/` 和 `server/` 从 `2095862f` 到 `c0c3810d` 没有变化。
- Android：APK 构建时的源码提交为 `ea27e0b4`；此后到 `c0c3810d`，`android/` 没有变化。

## Server 与数据库

2.0.3 的数据库 revision 为 `v2_41`（schema version `2.41`），2.0.0 为 `v2_35`。从 2.0.0 升级的自托管部署需要执行 `v2_36` 到 `v2_41` 的迁移，步骤见[升级指南](../upgrading.md)。

## 分发与后续版本

两个 Desktop 安装包的应用内更新下载地址仍是 `.invalid` 占位地址，新版本需要从下载入口手动安装。README 中的 iOS 入口新增 App Store，同时保留 TestFlight 测试版入口。

后续版本继续记录各平台的来源提交和文件摘要，并同步更新 README 下载表。上一个版本见 [2.0.0 发布说明](2.0.0.md)，开发和打包见[开发指南](../development.md)。

# Agents Anywhere 2.3.0

2.3.0 是一次接口更新（MINOR）：Agent 运行中也可以继续补充要求——默认**排队**到本轮结束后的下一轮，也可以**插话**，把这条消息注入当前轮的下一个步骤。同时修复了 Android 输入法键盘遮挡输入框的问题。该能力要求插件、Connector 与客户端同步升级。

## 产品变化

- **运行中排队插入（Web / Desktop / Android）**：会话里 Agent 正在工作时，发送按钮不再被中断按钮占据；发送的内容默认**排队**，在本轮结束后的下一轮开始处理。排队期间该消息以乐观条目留在时间线中，直到运行时把落库消息回传。
- **运行中插话插入（Web / Desktop / Android）**：Agent 工作时，输入框旁出现「插话」入口，把当前草稿直接注入**正在运行的这一轮**的下一个步骤，Agent 无需等本轮结束即可看到新要求。
- **Android 键盘不再遮挡输入框**：此前 `windowSoftInputMode` 为 `adjustNothing`，在非 edge-to-edge 设备上既不调整窗口也不派发输入法 insets，`imePadding()` 恒为 0，键盘会盖住输入框。现改为 `adjustResize`：旧设备由窗口调整顶起，edge-to-edge 设备继续使用 insets，两种模式互不叠加。

## 接口与协议

- 新增会话级能力 `session.queue`：声明该 Runtime 允许在 turn 运行中接收消息并排队到下一轮。`POST /api/v2/sessions/{id}/runtime/messages` 现在仅在 Runtime 声明可用的 `session.queue` 时接受运行中的会话，否则保持原有 409 `session is running`；排队不会覆盖在跑 turn 的 active-run 记录（中断与恢复语义不变）。
- 新增会话级能力 `session.steer`（DSH 侧此版本起真正实现）：声明该 Runtime 支持把消息注入在跑的 turn。客户端据此显示或隐藏「插话」入口。
- Runtime 协议新增 `session.steer` RPC（`mode: 'steer'`），DSH 桥的能力集 revision 升至 9。
- 能力驱动：未声明上述能力的 Runtime 行为与 2.2.0 完全一致，客户端不会显示对应入口。

## 升级提示

- **DSH 插件与 Connector 必须一起升级**：插件声明能力、Connector 转发，缺一不可。
- 插件升级（版本化 URL）：
  `dsh --profile <名> plugin add https://dsh.chyu.top/downloads/plugin/agents-anywhere-dsh-bridge-next-2.3.0.tgz`
- **Android**：Server 升级到 2.3.0 后，端内检查到新版本会提示升级并从下载地址获取新 APK（versionCode 14）。
- **Desktop**：端内更新比较 Server 版本与构建期烙入的 `serverVersion`，2.3.0 起安装包烙入 Linux/Windows 更新地址。
- **Web**：服务端升级后刷新页面即为最新。

完整的更新说明见 GitHub Release。

# 2.2.0

DSH 完整快照增加持久化分块上传。Connector 提交时逐页读取并逐条编码到临时文件，避免在提交时重新装载完整列表和整份 JSON 字节。稳定正文摘要标识上传；后端保存分块并返回已确认序号，网络重连和服务端重启后仅补传缺块。最终提交仍沿用原有完整历史替换，成功后才保存 checkpoint/ACK。最高快照序号独立持久化以拒绝旧上传；24 小时暂存和回执在启动及每小时自动清理，不依赖客户端再次上传。

最低 Server 与 Connector 均为 2.2.0；新增端点见 contracts/connector-snapshot-upload/1.0。没有针对旧 Server 的接口降级，请同时升级；其他客户端版本按 MINOR 规则同步。数据库迁移为 v2_42。旧 API 仍保留，旧 Connector 继续使用原完整 POST。

限制：原生历史变化会建立新的上传；暂存到期需要重新上传。Connector 的页缓存、去重 ID 和 Bridge 投影仍占内存；Server 最终仍完整解析快照 JSON。没有宣称端到端内存有界。

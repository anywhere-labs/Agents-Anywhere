# Agents Anywhere 2.2.0

2.2.0 是一次接口更新（MINOR）：DSH Runtime 的 Agent Teams 成员会话现在会同步到 Agents Anywhere，可以从主会话直接打开成员的完整对话；计划审批与工具输出支持 Markdown 渲染。该能力要求插件、Connector 与客户端同步升级。

## 产品变化

- **子 Agent 对话切换查看（Web / Desktop / Android）**：DSH 团队成员与一次性子 Agent 的会话以只读方式同步（不进入主列表、不可发送消息）。主会话 insights 面板新增「团队成员」分区，展示成员的运行阶段（启动中 / 活跃 / 失败）与上下文类型（全新 / 继承），点击即可打开该成员的完整对话；agent_call 卡片（`spawn_teammate`、`send_message` 等）带「查看对话」入口。
- **Markdown 渲染（Web / Desktop / Android）**：计划审批卡正文与 DSH 工具输出中的成文内容（非命令输出）按 Markdown 渲染，支持表格、代码块与公式；命令类工具输出保持终端样式。
- **团队工具卡片**：`spawn_teammate`、`team_task_*` 等团队工具在时间线中呈现为 agent_call 卡片，spawn 结果回填成员会话标识用于跳转。

## 接口与协议

- Runtime 协议：`session.meta.upsert` 的 meta 现在可以携带 `sourceState`（availability / reason / observedAt / observationOrigin），Connector 会将其转发给 Server。meta 结构为可扩展字段（`additionalProperties: true`），旧版 Connector 忽略该字段不受影响。
- 客户端应把 `sourceAvailability === "unavailable"` 且 `sourceAvailabilityReason === "dsh_subagent"` 的会话从主列表过滤，并通过成员面板 / agent_call 卡片提供入口。

## 升级提示

- **DSH 插件与 Connector 必须一起升级**：只有插件侧同步子会话而没有 Connector 的 sourceState 转发时，成员会话会以错误的可用性状态出现。
- 插件升级（版本化 URL）：`dsh --profile <名> plugin add https://dsh.chyu.top/downloads/plugin/agents-anywhere-dsh-bridge-next-2.2.0.tgz`
- Web / Desktop / Android：服务端升级到 2.2.0 后，各端按既有链路提示更新。

完整的更新说明见 GitHub Release。

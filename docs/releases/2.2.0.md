# 2.2.0

DSH 快照在 Connector → Server 之间增加持久化分块恢复与原子提交，基于 #332 的大历史优化和 #353 的客户端流。中断后相同正文只补传缺块，完整快照确认前保留旧历史；最终响应丢失可查询完成 receipt。

新增 `/api/v2/connector/ingest/uploads` 的 begin/chunk/commit 接口和数据库迁移 v2_45。Server、Connector 需同时升级至 2.2.0；其余端仅同步产品接口版本，无新增 UI。DSH → Connector 继续使用 `aa.dsh.v2.Sync.ingestSnapshot`，没有恢复旧 Bridge 协议。

暂存与 receipt 保留 24 小时，恢复要求重新捕获的正文相同。详见 [DSH 快照上传](../dsh-snapshot-uploads.md)。

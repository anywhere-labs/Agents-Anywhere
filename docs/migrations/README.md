# 迁移文档

当前部署升级请先阅读 [v2 升级指南](../upgrading.md)。`main` 已承载 v2，不能再把分支名当成旧版架构的别名。

- [早期 main 到 v2](main-to-v2/README.md)：保留早期审计基线、旧客户端迁移设计和旧版本部署步骤；其中数据库版本和 Redis 策略已过时。
- [邮箱账号与昵称](main-to-v2/email-accounts.md)：账号标识和旧用户名登录变化。
- [事件恢复 v2](event-recovery-v2.md)：事件恢复契约迁移背景。
- [旧存储 v2.3](legacy-storage-v2_3.md)：早期移除 Server 旧存储的历史记录。

这些历史清单未被自动勾选为完成；发布客户端、合并代码和完成某个生产数据库迁移是不同事项。

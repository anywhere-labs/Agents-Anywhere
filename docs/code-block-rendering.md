## 内容与业务约定

- Markdown 保留围栏提取、数学公式、文件链接及 Mermaid 路由。Mermaid 保留 250ms 调度、上一张有效预览、失败提示和源码折叠。
- 工具命令与 JSON 使用高亮；日志和配对命令保持纯文本，未知语言也是纯文本。不自动开启 ANSI、行号或换行。
- 最大高度与滚动由已有 ScrollArea 管理，内部 pre 不再创建第二层滚动视口。焦点落在滚动视口，复制不从 DOM 提取内容。
- 配对命令继续左文右按钮，复制反馈为两秒；会话代码块为 1.2 秒。组件卸载或内容更新会清理反馈定时器，旧异步结果不能覆盖新内容。
- 不按大小截断、关闭高亮或增加展开步骤；Monaco、原生 Android/iOS 和网络协议不变。

## 高亮与性能

高亮继续通过 `lib/code-highlight.tsx` 调用 highlight.js，保留原来的语言表、别名和 CSS 主题。语言只注册一次，没有新增高亮依赖、CDN 或 WASM 请求。主题切换由 CSS 完成。

主题仅对浅色属性色和暗色注释色做可读性修正，避免这些文字在 AA 的背景上对比度不足；不改变语言规则。

高亮内容与复制按钮的状态独立。`SourceCodeContent` 与内部高亮组件使用 React 记忆化，仅在代码或语言变化时重新分词。复制反馈、无关父组件更新不再重新执行整块高亮；本次不实现行级增量分词。

代码变化时仍同步高亮完整内容，与迁移前一致。组件卸载后释放 React 缓存，不建立全局正文缓存。没有长度降级、Worker 或行级虚拟化；超长代码和大量 DOM 的开销仍然存在。

## 验证边界

编译和自动化检查不能替代实际 Web/Electron 渲染验收。本次仅引入展示组件，继续使用 highlight.js，以保持现有语言覆盖和首次高亮开销；性能数据应对照相同构建条件下的原实现。

开启系统“减少动态效果”时，全局 CSS 的非零过渡时长会干扰 Mermaid 同步测量 SVG 几何尺寸，导致图表异常放大、初始视口看起来空白。Web 与 Desktop 统一将该模式下的过渡时长设为 `0s`，消除测量过程中的过渡；动画仍保留原有的极短时长及单次播放，以维持完成事件。Mermaid 的渲染算法、250ms 调度和失败后保留上一张图表的行为不变。

使用演示数据在 Web 和 macOS Electron 渲染器检查流程图、时序图、状态图和类图的亮暗主题；减少动态效果下的图表尺寸与正常模式一致，并保留源码展开和更新失败提示。这是组件级验收，不代表真实 Runtime 会话或各平台安装包的端到端验收。
